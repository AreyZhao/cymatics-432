432Hz 音流学

怎么玩

  • 拖动画面旋转视角，双指捏合 / 滚轮缩放。
  • 轻点画面：隐藏或固定界面。
  • 🎨 配色/琴键：可选 5 套配色，琴键可在 13 / 25 / 49 / 88 键之间切换（大琴键可左右滑动）。
  • 底部拖动频率滑块，图形会随频率换形状；范围 0 → ∞（拖到最右为无上限，也可在输入框直接填 ∞）。

五种驱动方式

  • 🎤 外音：手机外放音乐，麦克风收音，波纹跟着低音与节拍呼吸。
  • 🎧 系统声：电脑 Chrome/Edge 共享标签页时勾选「分享音频」，可只听系统声、不拾取麦克风；手机浏览器抓不到系统声，会自动切换成「页面内部声音」分析（放歌/天籁照样能驱动画面）。
  • 🎵 放首歌：选手机里的 mp3，页面自己播放；声音会实时换算成 0–∞ 的频率，直接改变图形形状。
  • ✨ 天籁：随机即兴；「🎛 设置 → 创作 → 换一首」按选定风格生成新曲并存进曲库。7 种风格：🌊 清寂流韵 / ☁️ 云野遥音 / 🌑 幽墟沉响 / ✨ 萤光碎舞 / 🏔️ 陵岳长歌 / 🌫️ 虚冥静息 / 💎 晶界流光。
  • 🎤 哼唱：对着麦克风哼旋律（每个音要稳定约 0.2 秒），自动量化成五声音阶配乐；可在「🎛 设置 → 哼唱」里**直接回放**，满意再保存 MIDI。
  • 🎹 音色：八音盒 / 电子琴 / 电钢琴 / 长笛 / 钟琴 / 手碟 / 马林巴 / 单簧管 / 电古筝 / 电琵琶 / 编钟 / 小提琴 / 竖琴 / 短笛 / 合成器。每首曲只用 1–3 件乐器，独奏时只用一种。
  • 🎛 设置面板：点右下角 🎨 打开三级菜单——音源 / 音色 / 外观 / 创作 / 哼唱，对应选项都在二级页里。

🤖 AI 识别（本地）

  • 实时判断当前声音是音乐 / 人声 / 鼓点 / 环境噪声，并显示音名和置信度。
  • 全部在本机计算，不上传任何音频。

浏览器兼容

  • Chrome / Edge / Safari / 三星浏览器：全部功能。
  • 微信内置浏览器：能看、能放歌、能开外音（首次会弹麦克风授权，允许即可）。
  • 老设备：不支持 WebGL 时会给出提示；帧率偏低时自动降低渲染量。

分享到微信

  • 微信只能打开网址，不能直接打开本地 .html 文件。
  • 把文件上传到 GitHub Pages / Netlify Drop 等免费静态托管，拿到 https 链接后分享，微信里点开即可查看。

音流学（Cymatics）：克拉尼图形由圆膜的贝塞尔模态 |Jm(z r)·cos(mθ)| 生成，振幅为零的节线处颗粒聚集。音频只在本机分析，不会上传。
保存的 WAV / MIDI 在浏览器下载目录里（手机一般是「文件管理 → 下载」）。MIDI 可以用 Signal（在线）、MuseScore、GarageBand、FL Studio 等编辑。
